# Bron — MVP бронирования столиков

Сайт, где гость видит схему зала и бронирует конкретный стол, а заведение
в реальном времени видит загрузку и рассаживает гостей.

## Запуск

Нужен только Node.js 18+ (сторонние пакеты не нужны).

```
npm start
```

- Сайт для гостей: http://localhost:3000
- Панель заведения (хостес): http://localhost:3000/admin
- Ссылка на конкретный слот: http://localhost:3000/?restaurant=sakura&date=2026-10-23&time=19:00

## Цвета столов

| Цвет    | Значение                                        |
|---------|-------------------------------------------------|
| Серый   | Свободен — можно забронировать                  |
| Красный | Забронирован на выбранное время                 |
| Синий   | За столом сейчас сидят гости                    |

## Что умеет

**Гость** (`/`): выбирает заведение, дату, время и число гостей → кликает на серый
стол на схеме → вводит имя и телефон → получает номер брони. Столы, где мест
меньше, чем гостей, затемнены.

**Хостес** (`/admin`): видит зал «сейчас» и счётчики загрузки; по клику на стол
может посадить гостей без брони, отметить приход по брони, отменить бронь или
освободить стол. Слева список броней на сегодня.

Все изменения сразу появляются у всех открытых страниц (Server-Sent Events).
Одна бронь занимает стол на 2 часа; бронь доступна с 10:00 до 21:00.

## Структура

```
server.js              сервер и API
data/restaurants.js    заведения и схемы залов (координаты столов)
data/bookings.json     брони (создаётся сам, при первом запуске — с демо-данными)
public/index.html      страница гостя
public/admin.html      панель заведения
public/hall.js         отрисовка схемы зала (SVG), общие функции
public/style.css       стили (светлая и тёмная тема)
```

Чтобы сбросить данные к демо — удалите `data/bookings.json` и перезапустите сервер.

## API

| Метод | Путь                                   | Что делает                              |
|-------|----------------------------------------|-----------------------------------------|
| GET   | /api/restaurants                       | заведения и схемы                       |
| GET   | /api/tables?restaurant=&date=&time=    | статусы столов на слот (без даты — сейчас) |
| POST  | /api/bookings                          | создать бронь                           |
| GET   | /api/bookings?restaurant=&date=        | брони за день                           |
| PATCH | /api/bookings/:id `{status}`           | seated / done / cancelled               |
| POST  | /api/walkin                            | посадить гостей без брони               |
| GET   | /api/events                            | поток живых обновлений                  |
